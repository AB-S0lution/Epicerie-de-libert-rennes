# Épicerie de Liberté, Rennes (démo)

- **Concept**: « La Dernière Vitrine ». Une vitrine éclairée la nuit, rideau métallique qui se lève, horloge 24 h de l'épicerie (jusqu'à 1h) et du relais colis (22h). Palette: bitume #0E1117, façade #161B23, craie #ECECE7, sodium (accent unique) #F4A93A (texte sur clair: #8F5207), ouvert #5CC98E, fermé #E0685A. Mode « Nuit » par défaut, « Jour » via `[data-theme="light"]` (bouton seulement, clé `liberte-theme`). Polices Big Shoulders Display Variable / Barlow / Barlow Condensed.
- **Source de vérité**: `PLAN.md`. Nom affiché « Épicerie de Liberté » (jamais « Épicerie de la Liberté »). Horaires en conflit entre sources: jamais présentés comme certains, mention visible « horaires à confirmer » (`src/data/hours.ts` garde les trois jeux). Aucune mention d'accessibilité tirée du pied de page de La Poste (« Accès PMR indiqué par le réseau Pickup, à confirmer en magasin »), aucune livraison d'alcool, pas de rayon alcool.
- **Données**: `src/data/*.ts`, chaque fichier porte un en-tête SAMPLE ou REAL. Catalogue (76 produits, prix, journal, 3 codes de suivi DEMO-000x) = exemples étiquetés. Les 11 avis sont des avis Google verbatim, attribués à la plateforme seulement (r2 cite l'alcool: page /avis/ uniquement, jamais en accueil).
- **Architecture**: pages HTML minces (`index.html`, `rayons/index.html`, ...) avec `data-page`; le plugin `renderPages` de `vite.config.ts` rend head/header/corps/footer à la compilation depuis `src/render/*` et `src/data/*`, puis `typo()` (espaces insécables avant `; ! ? :` et dans « »). Une page = un HTML + une entrée dans `src/render/registry.ts` + un `input` dans `vite.config.ts`.
- **Mouvement**: GSAP + ScrollTrigger + SplitText + Lenis (chargés en différé, `src/scripts/fx.ts`), animations CSS pilotées par le scroll (`.scroll-progress`), View Transitions inter-documents (volet sur la pastille « Ouvert »), IntersectionObserver pour les révélations. Transform/opacité uniquement. `prefers-reduced-motion`: histoire verticale statique, pas de Lenis, mises à jour instantanées.
- **Heures**: `src/lib/hours.ts` (jour 0 = lundi, minutes depuis minuit, plages après minuit rattachées au jour d'ouverture, fuseau Europe/Paris). Démo: `?heure=03:00&jour=lun`.
- **Art**: tout est SVG original (`src/lib/art.ts`): pictogrammes produits, devanture, bande de nuit, plan de quartier. Plus des photos d’illustration Unsplash (`src/data/photos.ts`, `public/photos/`, légende « Photo d’illustration »), jamais présentées comme le magasin. Aucun logo de transporteur.
- **Lancer**: `npm run dev`; **vérifier**: `npm run typecheck && npm run build`, puis `npm run preview -- --port 4176` (base `/Epicerie-de-libert-rennes/`). CI: pas d'URL absolue racine dans `dist/`, `404.html` à la racine, `public/.nojekyll`.
- **Pas de tiret cadratin** dans les textes, pas de `transition: all`. Pas de cookies ni de traceurs (localStorage seulement: thème, « Ma liste »).
- **Git**: ne jamais committer ni pousser sans demande.
